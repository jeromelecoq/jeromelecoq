# Jérôme Lecoq

**Associate Investigator at the [Allen Institute for Neural Dynamics](https://www.allenneuraldynamics.org/)**

I lead [OpenScope](https://www.allenneuraldynamics.org/projects/openscope), an open platform that turns community-proposed questions into standardized, large-scale neurophysiology experiments.

I work at the intersection of systems neuroscience, neural dynamics, two-photon microscopy, Neuropixels, computational imaging, and open science. Most of my current code and data work lives in collaborative Allen Institute repositories.

## Current work

- **[OpenScope](https://www.allenneuraldynamics.org/projects/openscope)** - Community-designed neuroscience at scale, from experimental planning through open data release.
- **[OpenScope Databook](https://github.com/AllenInstitute/openscope_databook)** - Reproducible Python notebooks for exploring and analyzing NWB datasets on DANDI.
- **[OpenScope Predictive Processing Community](https://github.com/AllenNeuralDynamics/openscope-community-predictive-processing)** - Open documentation, experiments, and shared analysis for testing models of predictive processing.

## Selected software

- **[DeepInterpolation](https://github.com/AllenInstitute/deepinterpolation)** - A deep-learning library for removing independent noise from systems-neuroscience recordings without clean ground-truth data ([*Nature Methods*, 2021](https://doi.org/10.1038/s41592-021-01285-2)).
